# Coordinate Pixel Quest — v5.2 Pixel Art World

A full GitHub Pages-ready game release, including **all 50 coordinate-art restorations and all 12 existing world areas**.

## New graphical overhaul

- Real native-resolution pixel-art atlases replace the old flat squares in Standard and Enhanced graphics modes.
- Original artwork for 13 biome variants (including five optional trails), with illustrated grass, flowers, canyon rock, cloud ground, marsh pools, volcanic terrain, snowy crystals, and celestial gardens.
- Illustrated native-resolution trees, crystals, mushroom groves, decorative landmarks and buildings.
- Animated directional explorer sprites and Pip fox sprite.
- Old flat renderer retained as Low graphics mode for maximum compatibility.
- Includes low-motion controls and graphics-quality settings.
- All original puzzles, optional routes, save progress, color wheel, keyboard hotkeys, and 44×44 finale remain.

## Install

Extract this ZIP and upload **all files** to the root of your existing `coordinate-pixel-quest` repository, replacing the older versions of files with the same names. Do not upload the ZIP itself. GitHub Pages should serve `index.html` from `main` → `/ (root)`.

If the old look persists, refresh with Ctrl+Shift+R. The new header should display **PIXEL ART WORLD · V5.2**. The new `.png` sprite atlas files are required.

Progress uses the unchanged localStorage key `cpq_pixel_valley_v1` and is compatible with v4/v5. Existing student progress is browser/device-specific.

No accounts, external dependencies, trackers, or API keys are required.
