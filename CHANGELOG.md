# Changelog

## v5.3 — Cartesian Coordinates (November 2, 2026)

- Changed the first two main puzzles to true bottom/left Quadrant I axes anchored at (0,0).
- Converted the other 48 quests to centered signed coordinates in all four quadrants.
- Moved X tick labels to the bottom; added X/Y directional indicators and clear origin markers.
- Added a Grid lines ON/OFF control for uninterrupted viewing of restored artwork.
- Corrected focus viewport indexing, target prompts, hint coordinates, mouse input, and gallery previews for signed coordinates.
- Kept all 50 pixel patterns, chapter progression and 16-bit assets.
- Moved to a fresh v2 local save key; prior saves are not automatically imported.


## v5.2 — Real 16-bit Pixel Art World (October 31, 2026)

- Rebuilt world terrain rendering using original 32×32 pixel-art tiles rather than flat-colored rectangles.
- Added five new PNG sprite atlases: terrain, biome decoration, structures, explorer animations and Pip.
- Added region-specific environmental objects and multi-frame directional explorer movement.
- Preserved all 50 quests, 12 areas, original puzzle grids, settings, save data, and story gates.
- Low graphics mode retains the previous renderer for older school Chromebooks.
- Added conspicuous in-game v5.2 release label and cache-busting asset versions.
